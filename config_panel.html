Config panel

Leadership tool for setting permissions, groups, and levels in bulk. Load the file from /config export so this page knows your roles, edit, then download and apply with /config import. Runs entirely in your browser — nothing is sent anywhere.

Load config.json from /config export — or start blank below. Without it, role dropdowns will be empty.

Roles

Dropdowns below list roles from the loaded export. To use a role that isn't here, add it by name and ID — in Discord with Developer Mode on, right-click a role and Copy ID. A role added by name alone can't be matched by the bot and won't apply, so the ID is required. If the role already exists on your server, re-running /config export is the tidier way to pull it in.

Command permissions

Restrict a command to a role. Manage Server always passes and can't be locked out. Known commands: start, tree_import, config_import, config_export, tree_add, tree_remove, tree_drop, project_delete

Special roles

Who may set things Universal, and who may sign off milestones. Blank means Manage Server only.

Groups, regions, teams

The values people can tag work with. Universal is always available and isn't listed here.

Levels

XP thresholds and names. The perk is descriptive text for now.
